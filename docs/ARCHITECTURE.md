# AEGIS Architecture

## M1
Generates 60 heterogeneous alerts: 20 incident alerts and 40 noise alerts across 4 demonstration incidents.

## M2
Correlates alerts; Proposer creates a root-cause theory; Skeptic challenges it using evidence; final verdict
contains confidence, severity, business impact, remediation and execution mode. Trust Ratchet enables earned autonomy.

## M3
Dashboard/presentation layer.

## M4
FastAPI integration layer serving the final frontend and incident action endpoints.
